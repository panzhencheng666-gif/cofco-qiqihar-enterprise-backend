# 地区公开农业数据扩展与来源访问修复

目标：只在地区数据模块扩展可核验农业信息，提高已发布数据自动提取和解释能力。
架构：复用地区公开指标库；新增独立指标解析器及作物目录，不修改平台产品/样本/供需框架。公报按统计年度读取；新闻背景明确资料期；市级背景不得伪装成村级事实。

- [x] 新增粮食、薯类、油料、蔬菜、经济作物及畜牧/产业/乡村指标规则。保留原单位和证据句；同口径面积产量才计算单产。
- [x] 接入四地公报及呼伦贝尔PDF附件、齐齐哈尔发改委加工报道；08:30与重试走同一采集保存链路。
- [x] 修复跨地区融合、跨年指标展示、不同年分子分母混算；成功提取后才更新对应指标核验时间。
- [x] 页面增加主题筛选、指标检索、覆盖说明；补充新指标释义，修正单位换算解释；来源提供完整地址和失败提示。
- [ ] 针对解析、数据库隔离、衍生计算与页面交互测试；受管本地部署并浏览器验收；记录实际数据数量与未覆盖项目。

限制：尚无本地作物证据的村级小品种不强行平均分摊。预测现有参数是模型假设，不是统计置信概率；全作物历史回测与村级遥感约束为后续独立阶段。

验收进展：解析、历史预测、地区隔离与无变化核验共14项定向后端测试通过；前端指标筛选与详情5项通过，前后端构建通过。公网未发布：云助手会话失效；本机无云CLI凭据和搜索API凭据。联网发现适配器已实现，但不能标记全网搜索已启用。
