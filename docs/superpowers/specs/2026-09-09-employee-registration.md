# 员工自主注册（已确认立即生效）
用户确认：注册后立即可用。新增账号固定 BUSINESS_OPERATOR，不能注册管理员。账号密码由现有 Keycloak 注册页处理，业务注册页通过真实 OIDC 身份填写姓名、单位、岗位、地区；选项复用邀请员工目录，角色固定普通账号。允许所选有效地区立即获得普通业务权限，不需要审核，不自动抢占地区负责人。邮箱由 IdP 管理，不以邮箱自动绑定已有员工。
业务注册必须在真实 OIDC 会话下提交并校验 CSRF；用户名来自认证声明，不能从请求指定。保留 admin 及已有用户名，避免冒领邀请或管理员。原子创建员工、普通角色、范围和身份绑定；并发提交只产生一份，不允许重试覆盖授权。身份认证成功但资料未完成的账号可继续填写；完成后重新认证进入业务页。中文错误提示，防止重复提交。
验证限于隔离库 55435 与独立 IdP realm：选项一致、越权角色拒绝、跨单位地区拒绝、重复/并发、注册中断重试、真实注册认证与登录、普通账号管理员接口拒绝。正式库不放测试账号；验证后部署原本地入口。不宣称阿里云短信已可用。
