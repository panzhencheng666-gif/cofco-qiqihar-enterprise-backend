# 地区公开搜索服务

地区数据后台调用 SearXNG JSON 接口。定时搜索、资料解析和估算由 Java 服务执行，不依赖聊天助手或浏览器。

本机：`SEARXNG_URL=http://127.0.0.1:63310`；仅绑定回环地址。配置和缓存放在 `~/Library/Application Support/COFCO Qiqihar Enterprise/regional-search`，配置密钥自行生成，权限 0600。`scripts/ensure-local-regional-search.sh` 使用固定镜像摘要，恢复当前项目自己的容器；launchd 每五分钟检查容器运行状态。需要 macOS 用户登录、Colima 和主机保持运行。它不能使休眠或断电的主机在 08:30 执行任务。

公开部署需要在常驻服务器部署同等服务，并为后台配置内部地址，不能照搬本机回环地址。每日北京时间 08:30 触发搜索，耗时取决于外部渠道；失败渠道按小时重试。验证码、超时和引擎失败必须显示部分完成或失败，不能声称全网覆盖成功。

公开搜索结果只用于发现可访问网页。数值解析目前支持已有的统计公报与专题解析器；其他网页保留可追溯出处。没有授权的未公开资料不能获取，未知口径数字不能直接混算。估算批次在数据库按地区和日期留存，当前估算只使用目标年前的可比公开历史值，不将目标年公开值重新包装为独立预测。
